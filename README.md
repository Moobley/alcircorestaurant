# Al Circo Ristorante Pizzeria Demo

Static multilingual website showcasing the restaurant for presentation purposes.

## Languages
- Spanish (default): `index.html`
- Italian: `index.it.html`
- English: `index.en.html`
- French: `index.fr.html`
- German: `index.de.html`

## Technology
- HTML5 + CSS3 + vanilla JavaScript
- Mobile-first responsive design
- WCAG 2.1 AA accessible
- CSP header configured
- No external dependencies

## Usage
1. Deploy all files to static host (Netlify, Vercel, etc.)
2. Verify all language files load correctly
3. Test responsive behavior on mobile/desktop
4. Check accessibility with screen reader tools
